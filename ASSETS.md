# Библиотека из согласованного листа

Использованы только ряды **1–3** изображения, предоставленного пользователем. Ряд 4 с ключом, дверью, окном, коробкой, кроватью, холодильником, столиком, растением и шкафом не извлекался и в манифест не входит.

## Состав

- `public/assets/objects/`: 8 предметов — desk, chair, pen, book, bag, apple, phone, banana.
- `public/assets/actions/`: 11 действий — eat, study, drink, meet, sleep, exercise, work, buy, watch, read, learn.
- `public/assets/places/`: 8 мест — home, school, library, park, hospital, store, restaurant, mart.
- `public/assets/manifest.json`: ID → путь, корейская и русская подпись, категория, публичная карта использования в 14 будущих раундах.
- `public/assets/catalog.html`: просмотр всех картинок и путей, без редактирования уровней.

Итого **27 отдельных WebP 512×512**. Иллюстрации вырезаны из листа без перерисовки. Внешние корейские подписи, имена файлов и заголовки рядов исключены из самих картинок; русские/корейские названия выводятся отдельно интерфейсом. Детали внутри исходных сцен сохранены. Поскольку исходник — общий лист 1536×1024, сами фрагменты имеют небольшое исходное разрешение; квадрат 512×512 получен масштабированием с полями, без обрезания до квадрата и растяжения пропорций.

Ранее сгенерированные альтернативы не используются в этой библиотеке и не входят в её архив. Старые корневые ресурсы прежней игры сохранены как исторические файлы; действующий контент использует только пути из нового манифеста.

## Словарь действий

| ID | Глагол | Перевод |
| --- | --- | --- |
| eat | 먹다 | Есть |
| study | 공부하다 | Учиться |
| drink | 마시다 | Пить |
| meet | 만나다 | Встречаться |
| sleep | 자다 | Спать |
| exercise | 운동하다 | Заниматься спортом |
| work | 일하다 | Работать |
| buy | 사다 | Покупать |
| watch | 보다 | Смотреть |
| read | 읽다 | Читать |
| learn | 배우다 | Изучать |

`가다` и `오다` остаются словарём формулировки вопроса о движении. Отдельных сцен для них на согласованном листе нет; в запланированных раундах 11–12 достаточно изображений пунктов назначения. Ненужные ученику 달리다, 춤추다, 쓰다 и 요리하다 в новую библиотеку не введены.

## План 14 раундов

Публичный план содержит только наборы картинок — **без правильных ответов**. В вариантах действий сделаны замены под словарь ученика:

- План 5: A — read/sleep/eat, B — exercise/drink/study.
- План 7: A — read/eat/work/sleep, B — meet/exercise/drink/watch. Два выбранных действия должны показываться двумя отдельными картинками.
- Остальные наборы предметов и мест сохранены согласно визуальному ТЗ. `mart` доступен как дополнительное согласованное место.
- Предмет/действие и варианты места хранятся отдельно; изображение не помечает правильную локацию. Направление движения задаётся вопросом.

Действующая игра по-прежнему содержит только два раунда MVP: MULTI_SELECT и YES_NO. Её второй раунд соответствует плановому раунду 3. Этот ресурсный план не добавляет 14 уровней и не меняет сетевую логику.

## Недостающие ресурсы

Для адаптированной карты 14 раундов: **нет**. Все указанные пути существуют. Отдельные иллюстрации «идти» и «приходить» не требуются текущим планом и не подменены произвольной картинкой.

## Проверка

```sh
npm run check:assets
npm test
```

Проверяются формат/размер каждого файла, наличие всех путей плана, отсутствие ряда 4, соответствие словарю и ссылки двух действующих раундов. Манифест и имена файлов не содержат ключей. Правильные ответы остаются в закрытом `content/rounds.json`.
