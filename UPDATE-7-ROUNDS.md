# Korean Duo — семь раундов

Обновлённый проект для существующих GitHub Pages (`docs/`) и Render (Node.js).

## Обновление действующего сайта

1. Распакуйте ZIP и замените файлы в корне существующего GitHub-репозитория (включая папки `content`, `public`, `docs`). **Не удаляйте `docs/config.js` со своим URL Render:** в ZIP указан шаблон `REPLACE-ME`; перенесите туда свой реальный URL или не перезаписывайте этот файл.
2. GitHub Pages продолжит публиковать `master` + `/docs`. На Render нужен Web Service (не Static Site), привязанный к тому же репозиторию, с командой `npm start`.
3. После автодеплоя Render откройте Pages URL, создайте новую комнату и пройдите все семь раундов. Активные игровые комнаты исчезнут после перезапуска сервера.

## Контент

1. Простые действия — 60 секунд
2. Новые действия — 50 секунд
3. Места — 50 секунд
4. Даты — 45 секунд
5. Время — 45 секунд
6. Количество — 40 секунд
7. Цена — 40 секунд

Каждый раунд состоит из двух карточек с тремя ответами каждая. Сервер хранит ответы; неизвестная карточка их не получает до итогового экрана. Иллюстрации в `public/assets`, JSON — `content/rounds.json`.

Примечание: иллюстрации дат/цен содержат надписи внутри картинки. Их следует визуально проверить при реальном размере экрана.
