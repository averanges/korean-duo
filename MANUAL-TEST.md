# Версия 2.1 — проверка 14 раундов

Локальная проверка 27 октября 2026. Backend: `http://localhost:3000`, отдельный Pages-preview: `http://localhost:3002/korean-duo/`. Две независимые браузерные сессии A/B прошли весь курс.

## Результат

- **16 автоматических тестов: 16 успешных**; полный курс отдельно пройден без таймера и с истечением всех 14 дедлайнов.
- В браузере после раунда 14 оба игрока получили завершение, 14/14 раундов и по 14/14 верных ответов. Промежуточных результатов не было.
- Ресурсы: 27 файлов WebP 512×512, все пути существуют, объекты ряда 4 отсутствуют в манифесте.
- `public` и `docs` синхронизированы. Рабочий `docs/config.js` и CORS-схема сохранены.

## Автоматические проверки

Транспорт и базовые ограничения проверяются на двухраундовой тестовой выборке, а действующий курс — целиком отдельными тестами. Проверены: приватность собственной задачи во всех 14 раундах, ключ напарника, teacher-поля не отправляются, допустимые ID/типы, дубликаты, количество выборов, блокировка после отправки, старые экземпляры, два места, права A, восстановление, отключение после отправки, перезапуск, OFF без дедлайна, 30/45/60/90 секунд, CORS и polling/WebSocket. Один тест ждёт настоящее 30-секундное истечение при отключённом напарнике.

## Повторить

```sh
npm run sync:pages
npm run check:assets
npm test
```

Для браузерной проверки запустите backend с `CLIENT_ORIGIN=http://localhost:3002`, затем `npm run preview:pages` во втором терминале. Откройте две свежие вкладки preview; не дублируйте вкладку с сохранённым местом.

1. Пройдите все 14 раундов и сравните с таблицей в `ROUNDS-14.md`.
2. Измените выбор до отправки; обновите страницу и проверьте восстановление.
3. В раунде 7 выберите один/два действия. В выборе места поменяйте один вариант на другой.
4. Повторите с таймером 30 секунд; дождитесь истечения без ответа. OFF должен оставаться OFF при переходах и повторе, пока A сам не изменит настройку.
5. Отключите игрока после отправки, отправьте ответ вторым, верните первого: оба должны получить один текущий раунд.

Проверка действующего GitHub Pages/Render выполняется после публикации нового коммита. Локальный cross-origin preview не обновляет опубликованный сайт.
